# Summarization-Tool-using-GenAI
<p>AI summarization refers to the use of artificial intelligence to automatically generate concise summaries of longer texts. This technology leverages natural language processing 
  (NLP) techniques to extract key points and condense information, making it easier to digest large volumes of text quickly.</p>

# How to run
- First you have to clone this repository , for that type.
  ```bash
  git clone https://github.com/balamahi077/summerization
  ```
- after that create new virtual envirement, type
  ```bash
  python -m venv venv
  ```
- before installing packages activate the virtual envirement, type
  ```bash
  cd venv
  Scripts\activate
  ```
- install required packages
  ```bash
  pip install requirements.txt
  ```
- Now you run this project...
  
>[!NOTE]
>To run this project click on run button on right coener top screen.
